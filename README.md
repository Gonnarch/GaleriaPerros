## 📝 Descripción del proyecto

Aplicación web en **React** que consume la API pública de **TheDogAPI** y muestra una galería de imágenes de perros en tiempo real. Cuenta con una página de inicio (Home) y una vista de listado (Entities) que renderiza las propiedades de cada imagen obtenida desde la API.

---

## 🧰 Tecnologías usadas

- **React 18** — librería de interfaz
- **Vite** — bundler y servidor de desarrollo
- **React Router DOM** — navegación entre rutas
- **Tailwind CSS v4** — estilos
- **shadcn/ui** — componentes de interfaz
- **lucide-react** — iconos
- **TheDogAPI** — fuente de datos

## 🚀 Pasos para ejecutar el servidor

```bash
# 1. Clonar el repositorio
git clone https://github.com/Gonnarch/GaleriaPerros.git

# 2. Entrar a la carpeta
cd GaleriaPerros

# 3. Instalar dependencias
npm install

# 4. Levantar el servidor de desarrollo
npm run dev
```

La aplicación quedará disponible en `http://localhost:5173`.
